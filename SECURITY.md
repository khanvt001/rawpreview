# Security

## Reporting a vulnerability

Please don't open a public issue. Use [Report a vulnerability](https://github.com/khanvt001/rawpreview/security/advisories/new) on GitHub to send a private report, with the steps to reproduce it and the app version.

RawPreview is maintained by one person in their spare time, so there's no guaranteed response time.

## Supported versions

Only the latest release gets fixes.
